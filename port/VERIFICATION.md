# Preview verification

This public snapshot contains independently accepted U61 framework/demo sources. It adds original MVC unobtrusive validation/Ajax and pinned local dependencies to the accepted U60 native hosting profile. Publication preserves official upstream history, licenses and reviewed implementation bytes while omitting private checkpoint history and build outputs.

The public build_demo.py quick start was exercised with fresh output, SDK10.0.101 and Core/ASP.NET Core10.0.2. An existing offline feed supplied pinned dependencies. It produced both local packages, restored and built a copied package-only Stockroom in Debug, and published Release. Five original Razor views compiled; the private compiler is absent from publish. Package/cache/published identities and exact served client assets were checked.

The rebuilt public demo passed58 browser assertions across / and /tenant/app with isolated Playwright1.63.0/Chromium153. These cover original required/number/range validation, direct server rejection, mandatory CSRF, Ajax form/link updates and callbacks, dynamic reparsing,409 preservation, native fetch, roles and logout. Root checks also exercise JavaScript-disabled validation, redirect and one-read TempData. Separate root/nested authentication-expiry regressions return401 for Ajax reload, preserve the editor, show the sign-in message and leave stock unchanged. All four hosts stopped normally and browser contexts closed; spools were empty.

Independent U61 implementation review additionally rebuilt an isolated adapter consumer and exercised length/equal-to/remote validation, all four original update modes, cancellation and callbacks under its stronger CSP. That accepted evidence is reused because publication inputs are unchanged; it is not counted as a new public-checkout run. Earlier accepted U60 evidence covers configuration rejection, loopback OIDC code/PKCE and token/security cases, SQLite compare-and-swap/rollback and separate-process reopen.

Real identity providers, certificate/private-key file loading, persistent cryptographic rings and deployed proxy infrastructure were not exercised. Included screenshots/video show accepted U59 and remain labeled accordingly. Source recompilation does not establish signed binary replacement, historical token/wire interoperability, full source API completion or .NET Framework/IIS parity.
